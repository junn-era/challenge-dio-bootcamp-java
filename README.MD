# 📖 Sobre o Projeto

Este projeto tem como objetivo colocar em prática os principais conceitos da **Programação Orientada a Objetos (POO)** utilizando Java.

A proposta original foi criada por **Camila Cavalcante** em parceria com a plataforma **Digital Innovation One (DIO)**, e aqui foi reproduzida, estudada e adaptada como parte da minha jornada de aprendizado em desenvolvimento backend com Java.

Durante o desenvolvimento foram aplicados conceitos fundamentais como:

* Abstração
* Encapsulamento
* Herança
* Polimorfismo

Além disso, o projeto trabalha:

* modelagem de domínio,
* relacionamento entre classes,
* organização de código,
* boas práticas de orientação a objetos.

---

# 🎯 Objetivo

Simular o domínio de um **Bootcamp**, criando entidades que representam:

* Bootcamp
* Cursos
* Mentorias
* Desenvolvedores (Dev)

A ideia é exercitar:

* criação de classes,
* atributos,
* métodos,
* herança,
* composição,
* encapsulamento,
* reutilização de código.

# 📚 Conceitos de POO Trabalhados

## 🔹 Abstração

Capacidade de focar nos aspectos essenciais de um domínio, ignorando detalhes desnecessários.

---

## 🔹 Encapsulamento

Protege o estado interno dos objetos e melhora:

* manutenção,
* segurança,
* organização do código.

---

## 🔹 Herança

Permite reutilizar e especializar comportamentos entre classes.

---

## 🔹 Polimorfismo

Permite tratar objetos específicos de forma genérica, aumentando flexibilidade e extensibilidade.

---

# 🧠 Conceitos Fundamentais

## 📦 Domínio

Representa o contexto do problema que estamos modelando.

---

## 🏗 Classe

Molde responsável por definir:

* atributos,
* comportamentos,
* estrutura dos objetos.

---

## 🧬 Objeto

Instância criada a partir de uma classe.

---

## ⚙ Método

Representa ações/comportamentos dos objetos.

---

## 🧾 Atributo

Representa as características e estados de um objeto.
